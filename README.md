# 1qaz

Сервис одноразовых ссылок: вставляешь URL (или любой текст), получаешь короткий PIN-код и QR-код. Тот, кто получил PIN, вводит его и получает исходную ссылку. Ссылка живёт 10 минут и удаляется после первого открытия или по истечении TTL.

Живая версия: https://1qaz.su/

## Возможности

- Генерация 4-значного PIN (переключается на 5-значный автоматически при большой нагрузке)
- QR-код для быстрой передачи с одного устройства на другое
- Автоматическое удаление ссылки по TTL (10 минут) или после открытия
- Возможность продлить время жизни ссылки и удалить её вручную
- Live-статус открытия через SSE и polling
- Защита от спама: лимит запросов на создание по IP, блокировка после неудачных попыток подбора PIN
- Фильтр опасных протоколов (`javascript:`, `data:`, `vbscript:`) во вставляемом контенте

## Стек

Node.js + Express, без базы данных — все ссылки и сессии хранятся в памяти процесса.

## Установка и запуск

```bash
npm install
npm start
```

Сервер поднимается на порту из переменной окружения `PORT` (по умолчанию `3000`).

```bash
PORT=8080 npm start
```

На Windows (PowerShell):

```powershell
$env:PORT=8080; npm start
```

## Структура проекта

```
server.js              — Express-сервер, API и раздача статики
public/                 — фронтенд (index.html, иконки, manifest, service worker)
```
